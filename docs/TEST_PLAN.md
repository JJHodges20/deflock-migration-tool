# Test plan

All suites run inside containers (`docker compose --profile test ...`). The browser suite shares the edge's network namespace and reaches the app at `http://localhost:3000`, a secure context like a person's browser at 127.0.0.1. Ordinary tests never call a public provider; the only live calls happen in the `camera-sync` worker and the setup jobs.
