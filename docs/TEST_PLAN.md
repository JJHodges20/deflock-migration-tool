# Test plan

All suites run inside containers (`docker compose --profile test ...`). Ordinary tests never call a public provider; the only live calls happen in the `camera-sync` worker and the setup jobs.

| Suite | Command | What it proves | Needs |
|---|---|---|---|
| Backend unit | `docker compose --profile test run --rm api-tests` (part) | normalization rules (decision 0001 D8) against the real M0 fixture, polyline codec, candidate selection (D6), config validation, boundary containment, Overpass policy behaviour (429 pause, 502 retry, HTML/remark rejection), Valhalla and geocoder adapters with mocked transports | nothing |
| Backend contract | same | every endpoint's success and error envelopes with fake providers: region, health, plan (standard only, null counts, not_assessed), OUTSIDE_SERVICE_AREA, VALIDATION_ERROR, ROUTER_UNAVAILABLE, NO_DRIVABLE_ROUTE, geocode coordinates/not configured, cameras unavailable/bad bbox, oversized body | nothing |
| Backend privacy | same | redaction of coordinates, keyed values, query strings, JSON keys; access log disabled; a plan request leaves no coordinates in logs | nothing |
| Backend regression | same | production code never imports tests/fixtures; layer dependency rules; requirements.txt matches pyproject; fixture files are labelled | nothing |
| Backend unit (M2) | same | snapshot validation verdicts (empty result and large drop quarantined, growth publishable); diff categories (added, changed, missing, reappeared, still missing); node and way ids never collide | nothing |
| Backend integration | same (auto-skips without `DEFLOCK_TEST_DATABASE_URL`) | M2 inventory matrix on PostGIS: promotion, identical-snapshot skip, same key across versions (history), lifecycle change via prefix, vanished records carried as `no_longer_mapped` with `missing_since`, reappearance, retention expiry, envelope flag on an outside record, quarantine then operator reject and accept (review jobs recorded), pruning of superseded and reviewed snapshots with raw-file cleanup, concurrent sync skipped under the region lock, upstream failure keeps the last good snapshot, `drop` policy variant | `db` service (test database created by `infra/database/initdb`) |
| Backend unit (M3) | same | coordinate-swap recognition with an explanatory note; candidate de-duplication; reverse lookup adapter and not-configured state; endpoint snap distances from the real fixture; maneuver index bounds, whole-shape coverage, and length-sum alignment; miles-to-metres conversion in the adapter; identical start and destination rejected | nothing |
| Backend live Denver cases | same (auto-skips unless the local geocoder and router answer) | ten reviewed addresses and landmarks resolve within tolerance with the correct inside/outside flag; a nonexistent street returns no candidates; reverse lookup labels a pin; five reviewed trips (downtown one-way grid, Capitol to Washington Park, Union Station to the Zoo and to DEN, Cherry Creek to the Highlands) route legally per the engine's edge attributes (no backward traversal, drivable road uses only, destination-only edges only at the ends), with aligned maneuvers and snap distances under 300 m | running stack |
| Backend unit (M4 assessment matrix) | same | on a synthetic metric street: camera on the traversed road (counted, explained); parallel frontage road (uncertain); overpass (uncertain, grade-separated flag); ambiguous equally close roads (uncertain); split segments of one street count as the same road; a same-named street elsewhere on the route is not the road at the pass; an unnamed cross way as close as the street is ambiguous; camera far from any road (not an encounter); conflicting orientation (reported, never excludes); multiple cameras on one pole (counted individually, one site); buffer edge and 25/50/100 m sensitivity; endpoint next to a camera; loop passing the same camera twice (counted once, two passes); outside-envelope detour (partial, record uncertain); Flock-only scope; no-longer-mapped record uncertain; missing snapshot or graph gives not-assessed, never zero; metric helpers answer in meters | nothing |
| Backend unit (engine adapters) | same | recorded `/locate` response de-duplicated per way and sorted by distance; recorded `/trace_attributes` edges parsed with shape indices; engine errors mapped to ROUTER_UNAVAILABLE | nothing |
| Backend integration (M4) | same | PostGIS proximity agrees with the metric index within a metre, excludes far and non-ALPR records, and measures envelope coverage as a length fraction; association cache round trip, replacement, pruning by graph version, and clearing for recompute | `db` service |
| Backend unit (M5 candidate search) | same | on a synthetic road network whose engine reports physical time but searches on penalized cost: a lower-exposure detour is found and shared by both preferences; a longer detour with unchanged exposure is not presented as a benefit and an over-budget zero-exposure candidate is rejected (then admitted when the limit is raised); repeated requests are deterministic; a record at the destination is unavoidable and never excluded; an engine refusing exclusions is handled; penalized cost never changes reported time; no silent degradation without assessment; a zero-exposure Standard route needs no search; baseline alternates are ranked without extra calls; budget exhaustion and the deadline are disclosed; candidates leaving the envelope are not ranked; a frontage-road camera counts as uncertain, not matched; Standard is always present and first | nothing |
| Backend adapter (M5) | same | the avoidance request uses only `linear_cost_factors` (encoded polyline plus factor) and `exclude_locations`; engine warnings are surfaced; more than 50 exclusions, factors below 1, and empty requests are refused before the engine; error 157 maps to router unavailable and no-path codes to no drivable route | nothing |
| Backend contract (M5) | same | the `search` block with status, calls, budget, outcomes, and meaning; `not_run` with explicit `not_assessed` outcomes when no assessment exists; with a fake assessor the penalize-penalize-penalize-exclude sequence converges and shared paths carry several labels | nothing |
| Live Denver cases (M5) | `docker compose --profile test run --rm api-tests` (auto-skips without live services) | all three preferences for the five reviewed trips: every option road-legal per `trace_attributes`, every avoidance option fully assessed with lower exposure within its bound and a distinct geometry, search within budget and deadline, deterministic repeat | running geocoder, router, and camera snapshot |
| Frontend unit | `docker compose --profile test run --rm web-tests` | type check; comparison summary, shared labels, outcome messages, raise-limit action, not-assessed warning (M5); compare-list in the shell; planner reducer (confirmation, swap, late-response discard, cancel, pins, clear trip, no-match state, bounded controls); format helpers; Planner shell with mocked fetch (typed input persists, coordinate confirmation, geocoder-not-configured state, scope controls); camera legend summary counts; Data Health panel rendering inventory counts, diff, pending review, and recent syncs | nothing |
| Browser smoke | `docker compose --profile test run --rm e2e` (stack must be up) | at 390/768/1440 px: page loads, coordinates confirm, one real routing request through edge -> api -> valhalla returns the Standard route with directions plus the M5 search disclosure (all three preferences requested; every avoidance option fully assessed, lower exposure, distinct geometry); outside-pilot trip shows OUTSIDE_SERVICE_AREA; Data Health shows snapshot and graph; address-to-address planning with candidate confirmation through the local geocoder; explicit no-match state; swapped-coordinate explanation; km/mi toggle without a new request; map initialisation (canvas, worker, legend after load, no worker errors); pin-to-pin planning on the rendered map (skips itself when the browser has no WebGL2); a diagnostic WebGL probe that only reports | running stack with graph, snapshot, and imported geocoder |
| Compose smoke | `scripts/smoke_test.ps1 [-CheckRestart]` | every service healthy, data health, routing request, basemap range support and fonts, restart keeps snapshot and graph | running stack |

Not covered yet (later milestones): full browser flows with address search (M6), outage/backoff/graph swap behaviour over time (M7). A passing algorithm test never certifies the physical-world inventory.
